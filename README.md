### 🚀 Highlighted Portfolio Projects

#### 📈 [1. E-Commerce Customer Churn Analysis & Forecasting]([Link to Repo])
* **Objective:** Pinpoint operational bottlenecks causing customer drop-offs during Q3.
* **Stack:** Python (Pandas, Scikit-Learn), SQL (PostgreSQL), Tableau.
* **Impact:** Identified a 14% drop-off rate at the payment interface; driven UI fixes that recaptured an estimated $42K in monthly revenue.

#### 🗄️ [2. Operational Supply Chain Automation Pipeline]([Link to Repo])
* **Objective:** Automate manual daily CSV exports and clean historical vendor delivery metrics.
* **Stack:** Python, Google BigQuery, GitHub Actions (Cron scheduling).
* **Impact:** Reduced data extraction lag times from 6 hours weekly down to 0 minutes, ensuring error-free dashboard updates.

#### 📊 [3. Executive Financial Performance Dashboard]([Link to Repo])
* **Objective:** Consolidate multi-currency revenue metrics across three separate ERP software systems.
* **Stack:** SQL, Power BI, DAX modeling.
* **Impact:** Enabled regional VPs to filter organic margins by territory dynamically, eliminating manual ledger reconciliations.
